需要 VPN 权限

DNSSwitch 通过系统 VPN 接口接管 DNS 查询：所有 DNS 请求会进入应用，按你配置的通道（传统 DNS / DoH / DoT）解析后再返回。

本应用不会转发你的其他网络流量，不会收集任何 DNS 数据，不含任何广告。被其他设备信任的本地网络（如公司内网）解析可能受影响，可随时在系统设置中断开。

预设管理

把常用的 DNS / DoH / DoT 服务器存成预设，随时一键切换。也可从 txt 文件批量导入。

还没有自定义预设
在上方通道卡片点「＋ 存为预设」，或导入 txt 文件
从 txt 文件导入
每行一条：地址 空格 名字 空格 分类
例：223.6.6.6 阿里云 DNS · 2400:3200::1 阿里云 DNS · dns.alidns.com 阿里云 DoT · https://dns.alidns.com/dns-query 阿里云 DoH
分类写在行末，dns / doh / dot 均可，不区分大小写；同分类同名字的 IPv4 与 IPv6 会自动合并成一条。

存为预设

给这条服务器起个名字，之后可在对应通道卡片一键切换。同名同分类的预设会自动合并（IPv4 / IPv6 互补）。
